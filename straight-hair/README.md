# 长直发版本

纸笺采用「梅枝小信笺」样稿：折叠纸头、细朱砂边框、米白纸纤维、底部小梅印。无字素材为 `assets/paper-folded-v5.webp`，祝福正文仍由页面单独排版。悬挂、展开与三维翻面使用同一张纸面；背面按新边框计算安全文字区域。八张纸笺的初始角度为 -8° 到 7°，各自以 6.8–9.3 秒的周期轻摆 1.2–2.1°，绕树枝挂点摆动。贺卡未打开、摘笺阅读、键盘聚焦或页面不可见时暂停；系统减少动态效果时保留静态角度。

开场为无文字的米白对开贺卡。点击整张封面，两片纸页在 1.2 秒内沿左右折痕向外翻开，中间场景固定不动；展开后才启用八张便签。支持触屏及回车/空格，减少动态效果时改为轻淡入；关闭状态使用 inert、禁用按钮和事件拦截防止提前摘笺。刷新页面可重新打开贺卡。

此入口沿用主站的纯静态结构、八张纸笺、三维拖动翻面、人物走路与伸手、收齐后的单纹理轻微风动，以及手机可视区域排版。

人物素材位于 `../assets/straight-hair/`，控制器为 `../character-straight.js`。十张完整插画由内置 image_gen 在原姿态基础上编辑发型生成：普通长直发，不扎发、不留刘海；额前发量减少并上提，后发梢为自然分开的几缕，不做整齐内扣。仅最后比耶姿态保留头上红色花瓣与墨镜。

每张图使用其实际画布尺寸和透明区域边界计算脚底锚点、大小及伸手位置；结尾保持原始 1024×1536 坐标，以兼容现有局部风动。

人物大小以头顶到鞋底的实际身高校准，统一为 352 个场景单位；抬手、比耶和头上花瓣不会计入身高，避免姿态切换时整体缩放。

结尾微动按实际经过时间计时，低帧率不会拖长约 12 秒的摆头周期；页面隐藏时仍暂停。头部向屏幕右下方（人物自身左侧）缓慢偏转约 6°，略微下沉再回正；身体、手和脚保持稳定。

生成提示词及 PNG 原图随独立交付包提供。主站入口保留原版人物。
