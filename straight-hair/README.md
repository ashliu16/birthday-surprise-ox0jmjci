# 长直发版本

此入口沿用主站的纯静态结构、八张纸笺、三维拖动翻面、人物走路与伸手、收齐后的单纹理轻微风动，以及手机可视区域排版。

人物素材位于 `../assets/straight-hair/`，控制器为 `../character-straight.js`。十张完整插画由内置 image_gen 在原姿态基础上编辑发型生成：普通长直发，不扎发、不留刘海；额前发量减少并上提，后发梢为自然分开的几缕，不做整齐内扣。仅最后比耶姿态保留头上红色花瓣与墨镜。

每张图使用其实际画布尺寸和透明区域边界计算脚底锚点、大小及伸手位置；结尾保持原始 1024×1536 坐标，以兼容现有局部风动。

人物大小以头顶到鞋底的实际身高校准，统一为 352 个场景单位；抬手、比耶和头上花瓣不会计入身高，避免姿态切换时整体缩放。

结尾微动按实际经过时间计时，低帧率不会拖长约 12 秒的摆头周期；页面隐藏时仍暂停，幅度保持约 0.6°。

生成提示词及 PNG 原图随独立交付包提供。主站入口保留原版人物。
