# 树枝头 · 生辰笺

给寿星的一页纯静态生日网页。梅枝上的八张纸笺会轻轻摇动；点击抽出，左右拖动翻看纸张背面的祝福。点击“收下这张”后，纸笺和红绳离开枝头。收完八张，女生转为面向前方的站姿，戴上墨镜，左手斜向上比耶（画面右侧）。

开场下方仅显示“点开纸笺，拖动翻面”。收齐后，人物下方才出现祝福：“生辰喜乐，岁岁安宁。愿前路明朗，诸事顺遂。”

开场女生直立从右侧探出半个身子，双手扒住手机右边缘，头、肩和半边身体露在边缘左侧，抬头望向纸笺。点击后先走到所选纸笺下面，再伸手摘取；两侧高处的纸笺会使用踮脚姿态。收到祝福后放下手，继续望向枝头。人物动作使用独立插画和轻量 CSS / Web Animations，手机可直接触控，无需悬停。

“休息”纸笺的右上角附有一朵朱砂红梅花。花与纸共用三维旋转、弯曲和收取动作；翻到背面时，纸张自然遮住位于正面的花。

不需要后端、账号或数据库。图片、字体、Three.js 和手势动画库全部随站点提供，没有外部 CDN、广告或统计脚本。进度只在本次打开期间保留，刷新可重新体验。

## 修改

- `script.js`：`messages` 是完整正面和背面文案，`previews` 是枝头短句。
- `character.js`：人物姿态、移动目标、屏幕边缘定位和动作时序。
- `index.html`：纸笺位置、红绳长度、花瓣、网页标题和收齐后的祝福语。
- `style.css`：版式、配色、飘动和人物切换。
- `assets/`：独立的梅枝底图、人物姿态图、空白纸笺、红绳、花瓣和字体。

直接将目录托管为静态站点即可。键盘可用回车打开、左右方向键翻面、Esc 收下。没有模式切换按钮；无法创建 WebGL 的浏览器仍可阅读双面文字。
