# 树枝头 · 生辰笺

给寿星的一页纯静态生日网页。梅枝上的八张纸笺会轻轻摇动；点击抽出，左右拖动翻看纸张背面的祝福。点击“收下这张”后，纸笺和红绳离开枝头。收完八张，女生转为面向前方的站姿，戴上墨镜，左手斜向上比耶（画面右侧）。

梅枝为从左侧自然伸入的一枝，保留不规则枝节和逐渐变细的末梢，纸笺按枝杈错落悬挂。结尾正面人物始终使用同一张原始插画：头部以脖子为轴缓慢偏转至约 0.6° 再回正，一次往返约 12 秒；发梢和裙边只有局部轻微风动。身体、手和脚固定，不替换人物图片、不循环改变透明度。该动画仅在收齐后播放，离开页面时暂停，返回后接着播放，响应系统减少动态效果设置；无法创建 WebGL 时保留完整静态插画。开场、走路与摘笺姿态保留。

开场下方仅显示“点开纸笺，拖动翻面”。收齐后，人物下方才出现祝福：“生辰喜乐，岁岁安宁。愿前路明朗，诸事顺遂。”

开场、走动、摘笺和等候时，女生头上没有梅花点缀；仅在最后戴墨镜比耶的姿态保留头上的红色梅花。枝头梅花、飘落花瓣与纸笺上的梅花照常保留。

右侧探头姿态的眼睛与后续人物统一为简洁的黑色豆豆眼，保留抬头看纸笺和双手扒住边缘的动作。

开场女生直立从右侧探出半个身子，双手扒住手机右边缘，头、肩和半边身体露在边缘左侧，抬头望向纸笺。点击后先走到所选纸笺下面，再伸手摘取；两侧高处的纸笺会使用踮脚姿态。收到祝福后放下手，继续望向枝头。人物动作使用独立插画和轻量 CSS / Web Animations，手机可直接触控，无需悬停。

“休息”纸笺的右上角附有一朵朱砂红梅花。花与纸共用三维旋转、弯曲和收取动作；翻到背面时，纸张自然遮住位于正面的花。

不需要后端、账号或数据库。图片、字体、Three.js 和手势动画库全部随站点提供，没有外部 CDN、广告或统计脚本。进度只在本次打开期间保留，刷新可重新体验。

## 手机适配

触屏点击后的走路阶段为 0.6–0.8 秒，以均匀速度移动并交替迈步，然后切换到伸手或踮脚摘笺。走路位移使用 linear，避免先慢挪再突然冲刺。键盘操作和系统减少动态效果设置仍使用即时定位。

点击事件的次数为 0 时也会播放走路；只有真正的 Enter / 空格键操作走即时路径。旧内核缺少 Web Animations API 时使用 CSS 过渡移动，不会因此直接跳到终点。

页面跟随手机的实际可视高度调整，并预留刘海和底部手势区。梅枝纸笺、人物和下方文字分别计算大小与位置；短屏会缩短悬绳，人物保持可见，祝福不会被压出画面。纸笺的触摸区域至少 44 像素宽。

竖屏以枝头在上、人物在下排布；横屏改为左侧纸笺、右侧人物，阅读操作放到纸笺旁边。旋转屏幕时会重新布局；已收下的纸笺保留，正在阅读的纸笺会合回枝头，不计为收下。

## 修改

- `script.js`：`messages` 是完整正面和背面文案，`previews` 是枝头短句。
- `character.js`：人物姿态、移动目标、屏幕边缘定位和动作时序。
- `index.html`：纸笺位置、红绳长度、花瓣、网页标题和收齐后的祝福语。
- `style.css`：版式、配色、飘动和人物切换。
- `assets/`：独立的梅枝底图、人物姿态图、空白纸笺、红绳、花瓣和字体。

直接将目录托管为静态站点即可。键盘可用回车打开、左右方向键翻面、Esc 收下。没有模式切换按钮；无法创建 WebGL 的浏览器仍可阅读双面文字。
