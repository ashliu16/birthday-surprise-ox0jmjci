# 树枝头 · 生辰笺

给寿星的一页纯静态生日网页。梅枝上的八张纸笺会轻轻摇动；点击抽出，左右拖动翻看纸张背面的祝福。点击“收下这张”后，纸笺和红绳离开枝头。收完八张，女生放下手，转为面向前方的站立形象。

不需要后端、账号或数据库。图片、字体、Three.js 和手势动画库全部随站点提供，没有外部 CDN、广告或统计脚本。进度只在本次打开期间保留，刷新可重新体验。

## 修改

- `script.js`：`messages` 是完整正面和背面文案，`previews` 是枝头短句。
- `index.html`：纸笺位置、红绳长度、花瓣和网页标题。
- `style.css`：版式、配色、飘动和人物切换。
- `assets/`：独立的梅枝底图、两种人物姿态、空白纸笺、红绳、花瓣和字体。

直接将目录托管为静态站点即可。键盘可用回车打开、左右方向键翻面、Esc 收下。没有模式切换按钮；无法创建 WebGL 的浏览器仍可阅读双面文字。

## 字体和开源说明

本页字体是 [霞鹜文楷](https://github.com/lxgw/LxgwWenKai) 的字符子集，字体族重命名为 BirthdayHand，保留 SIL OFL 1.1 许可证。后续增加文案中的新汉字时，需要更新字体子集；未包含的字会使用本机楷体或衬线字体。

Three.js、Motion 和 Paperlab 相关许可证及修改说明保存在 `licenses/`。本页梅枝、人物和纸笺为本项目生成的独立插画素材。
